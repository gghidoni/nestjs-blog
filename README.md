# NestJS Blog API

Small learning project created to experiment with NestJS, TypeScript and
MongoDB through a simple REST API.

The application includes user management, optional user settings and posts
associated with users. It is an experimental project, not a production-ready
application.

## Run locally

```bash
docker compose up -d
npm install
npm run start:dev
```

The API runs at `http://localhost:3000` and MongoDB is exposed locally on port
`27018`.
